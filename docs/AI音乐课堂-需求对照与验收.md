## 一之三、2026-11-16 补强：课堂环节拆解（教案）

需求里「上课流程的拆解包括这节课的各个部分需要干什么」，此前只有 5 步操作界面，没有一份教师能直接照着上的教案。本轮在确认歌曲后的第 ② 步新增教案面板：

| 环节 | 估算时长 | 目标 | 页面位置 |
|---|---|---|---|
| ① 导入 · 试听确认 | 2 分 | 确认目标曲目，建立整体印象 | 第 1 步「找歌确认」 |
| ② 认识这首歌 · 作者与创作背景 | 3 分 | 知道谁写的、为什么写 | 第 2 步背景资料卡 |
| ③ 逐句学唱 · 音调／注意事项／停顿／休止／乐理 | 每句 2 分 | 逐句解决音高与节奏 | 第 3 步逐句卡片 |
| ④ 听范唱 · 预备拍 · 统一进入 | 4 分 | 统一速度与起音位置 | 第 4 步左侧播放器 |
| ⑤ 逐句演唱 · 评分与纠正 | 每句 2 分 | 每句拿到可定位反馈并复唱 | 第 4 步右侧录音区 |
| ⑥ 完整演唱 · 趣味收尾 | 4 分 | 连回整首歌，可视化鼓励 | 第 5 步趣味舞台 |

**确定性推导，不编造**：环节与时长由 `buildLessonPlan(song)` 从已核对数据算出——句数、音符数、BPM、`4×60/BPM` 秒的预备拍、全曲秒数、背景条数与核对状态、休止与换气处数量、自动触发的乐理知识点。每环节都带 `basis` 数据依据与 `here` 页面操作路径，可展开查看；乐理点显示为原站 `chip` 组件。以《小星星》为例：4 句 / 28 音 / 88 BPM / 全曲 21.82 秒 / 4 拍预备 2.7 秒，合计 29 分钟，余 11 分钟机动。

**教学方法科学**：顺序按唱歌教学常用的「整体感知 → 分句模唱 → 完整表现 → 即时反馈 → 趣味巩固」编排，每句唱完立刻给可定位反馈，避免把错误练熟；每环节分别列出老师动作与学生动作。一课时按 40 分钟估算，若自然时长超过 40 分钟（如 8 句曲目约 45 分钟），页面给出**分 2 课时**的具体拆法，而不是把 45 分钟硬塞进 40 分钟。文档明确标注：时长是可按班级情况调整的估算值，不是课程标准规定值；不引用任何教材页码或教研结论。

**与准确性机制一致**：资料级曲目（70 首）不生成假的逐句教学内容，环节自动改成可执行的「按句教」或「欣赏课」脚本；教案底部说明评分阈值与「范唱是电脑合成的人声」。「复制教案文本」生成纯文本备课稿，`file://` 下若浏览器禁止剪贴板，会自动展开可全选的文本框。

**UI 仍保持原站**：教案面板沿用 `panel / chip / btn` 与原站米色＋墨绿，所有新样式限定在 `#studio-root`；真实浏览器截图目视核对过，无深色区域、无浮动按钮、无登录弹窗。

## 二、内容准确性保障机制（重点）

### 2.1 拆解结果准确

1. **谱面严格校验，不静默修正**：简谱按小节逐拍核对，跨小节、拍数不足、时值不合法、无法识别的记号一律让构建失败（`parseScore()`）；生成的 lesson 必须通过项目既有 `LessonCore.validate()`。
2. **不编造未核对的谱面**：70 首资料级曲目只登记名称、作者、年级、类别与可核查背景，**不写 notation、不写 phrases**；页面上它们不能按逐音教，改为可执行的「按句教 / 欣赏课」脚本，并提供「上传 demo 自动整理」入口。宁可少给谱面，也不给一份看起来能唱、实际是猜的谱。
3. **内置谱面标注来源与核对状态**：项目内已波形验收的《茉莉花》《两只老虎》标 `score-checked-local`；其余通行唱本标 `needs-teacher-review`，并写明教学调规整、可能与课本版本不同，上课前请老师逐句核对。
4. **歌词自动对齐如实标注**：`exact / melisma / multi-syllable / needs-lyrics` 四种状态，任何不整齐的地方都列出具体警告（如「末字按拖腔跨 3 个音，请核对」），不假装识别 100% 准确。
5. **上传拆解是「推测」而非「定论」**：调性由音级分布推测、速度吸附到常用 BPM、分句按静音/拍数切分，逐项标 `needsReview`；带伴奏/多人/混响会拉低置信度并提示重录；**不做语音识别，不生成歌词**，老师填词后才逐字对齐。

### 2.2 教学方法科学

1. **教学结论全部由谱面确定性推导**，不由模型自由生成：每条「演唱注意事项」都带 `noteIndex`，可追溯到具体音符；每个乐理知识点都带 `at[]` 触发位置与 `why[]` 依据。
2. **每条知识含 `basis`**（谱面时值／谱面音程／分句结构／通用教学法）与一条课堂上可立刻执行的 `tip`，老师能判断可信度。
3. **不做因果推断**：只描述谱面事实与练习动作（「这个音要唱满 2 拍」「先把跳进前后两个音摘出来听准」），不出现「气息不足」「紧张」「方法不对」这类无法从声学数据推出的判断。此约束沿用项目既有 `coaching.cjs` 声明。
4. **改进方向与既有诊断规则对齐**：评分结果同时给出句级具体建议和 `coaching.buildCoaching()` 的规则链结论，两者可对照查看。
5. **范唱诚实标注**：伴奏与「人声」都是电子音合成，不是真人录音，页面明确说明；示范用的元音表按歌词字扩展，但从不伪装成真实演唱。

### 2.3 音准判定精准

1. **测量条件明确**：16 kHz 单声道、单人清唱、1–20 秒；静音、削波、周期性不足（伴奏/多人/噪声）、音段数与参考不符一律判**无效、不给分**，只给重录建议。
2. **基频算法**：归一化自相关求基频，清晰度阈值 0.85；音段内取中位数、剔除八度误判帧、过短「幽灵音段」并回相邻段；整体高/低八度按**八度等价**折算并如实标注，不把音区不同判成唱错。
3. **逐句独立对齐**：`phraseLesson()` 为每句构造独立参考（拍号/调号/BPM 不变，只取该句音符与歌词），学生唱哪句就按哪句对齐，不拿整曲参考硬套半句录音。
4. **阈值与公式全部公开**：音分阈值 35（约 1/3 半音）、起音阈值 0.12 秒；总分 = 音准×0.55 + 起音×0.30 + 速度×0.15，每个分项的原始值、得分与公式都写在结果里；A4=440Hz、12-TET 校准说明一并输出。
5. **置信度与可靠度**：输出整体 `confidence`；单个音若基频置信度偏低或含八度伪帧，标 `reliability: low` 并建议复测确认，避免把一次可疑测量当成定论。
6. **分数不是学习评价**：结果明确写「分数是本次录音相对参考谱面的声学吻合度，不是声乐水平或学习成果评价」。

## 五、已知边界（如实说明）

1. **曲库不是「全课本谱面」**：70 首只有元数据与背景，不能按逐音教；它们可以按「按句教 / 欣赏课」脚本完整上，但没有逐音范唱。原因是拿不到逐一核对过的谱面，硬编会出错；扩充方式已闭环——上传音频自动拆解，或沿用项目既有的简谱/MusicXML/MIDI 导入。
2. **上传拆解不做语音识别**：调性、速度、分句是推测，歌词需老师填写；适合「老师有一段清唱、想快速得到逐句教学框架」的场景，不能替代人工校谱。
3. **音准测量仍限单人短乐句、无伴奏**；多人齐唱、带伴奏录音会被判无效，不产出分数。这是既有算法的物理边界，没有伪装成「全场评分」。
4. **范唱是电子合成元音**，不模拟民族唱腔与表情；页面已标注。
5. **直接双击 HTML 时**：麦克风实时录音依赖浏览器对 `file://` 的安全策略；若被拒绝，页面会引导用「上传录音文件」，或用 `npm start` 在本地服务下打开。其余功能（检索、试听、逐句、播放、预备拍、评分、游戏化、上传拆解）在 `file://` 下均验证可用。
6. **背景资料不写具体教材版本与页码**，不确定的署名一律标 `needs-review`；正式出版或公开使用前请按所用课本复核。

```bash

E:/文件大集合/AI音乐课/shanyin-demo/public/index.html
```
