# 声入山野 · 公网上线就绪度评估报告

**评估日期**：2026-09-20
**评估标准**：以一个可公开上线、供乡村小学音乐教师实际使用的标准审视
**结论**：核心功能真实、工程底子扎实（106/106 测试绿、零第三方依赖、诚实声明贯穿），但**距离"公网上线"还有一档关键缺口**——主要是部署形态、安全加固、隐私合规与可运维性，功能层面则是"从单曲演示走向多曲/多人通用"。

---

## 📌 TL;DR（执行摘要）

- **能公开上线吗？** 还不能。当前是"本机演示级"完成度，架构为单机 127.0.0.1 监听 + 本地 JSON/WAV 存储，未做进程守护、HTTPS、反向代理、日志/监控、数据备份。
- **最值得先改的 3 件事**：① 部署形态（进程守护 + HTTPS + 0.0.0.0 配置化）；② 隐私合规（录音自动删除、未成年人数据告知、Cookie 加 Secure）；③ 上线必备的安全/运维基线（请求体大小统一、慢查询、密钥轮换、备份）。
- **功能层面最大的杠杆**：多首歌 + 多人混唱分析，决定它从"《茉莉花》单曲演示"变成"通用乡村音乐教学工具"。
- **好消息**：诚实声明、零依赖、账号隔离、版权闸门这些"可信度工程"已经做得很到位，是它的护城河，务必保持。

## 一、🔴 阻断级：安全与合规（上线前必须解决）

### 1.1 隐私与儿童数据合规（最高优先级）

乡村音乐课堂的核心使用者是**未成年人（小学生）**，其录音属于敏感个人信息。当前：

- 录音存 `.local-data/audio-attempts/`，**永久保留、无自动删除**——文档自己在"功能边界"里也承认"录音未做课堂结束后自动删除"。
- 无监护人授权、无数据留存期限、无"如何删除"的明确告知。
- 服务器重启后会话失效（内存态 `Map`），这对上线是隐患不是特性。

**必须做**：
- [ ] 录音设置保留期限（如 30 天）或"课堂结束自动删除"，并在界面明示
- [ ] 首次录音前弹出**未成年人数据采集告知 + 教师/监护人授权确认**
- [ ] 提供"一键删除我的全部录音"入口
- [ ] 补一份简短的《隐私政策 / 数据处理说明》页面

### 1.2 Cookie 与传输安全

- 当前 Cookie：`HttpOnly; SameSite=Strict; Path=/; Max-Age=…`——**缺少 `Secure` 标志**。上线若走 HTTPS，必须补 `Secure`，否则会话 cookie 可能被明文传输。
- 服务默认 `127.0.0.1`，上线需配置化监听 `0.0.0.0`，且必须前置 **HTTPS/TLS 终止**（Nginx/Caddy），绝不能裸 HTTP 暴露公网。
- `/api/` 有 Host 白名单（仅 127.0.0.1/localhost）——这本身就是**为了本机演示写的**，上线必须改掉或由反向代理重写 Host。

### 1.3 安全加固

- [ ] 登录限流当前按 `remoteAddress` 计数——一旦前面挂了 Nginx，`remoteAddress` 全是 127.0.0.1，限流失效，需改读 `X-Forwarded-For`（并只在可信代理下信任）。
- [ ] 会话 token 存在内存 `Map`，多实例部署不共享；单实例无进程守护时，重启即全员掉线。生产需落地到持久会话或改用签名 token。
- [ ] 密钥 `TEACHING_API_KEY` 曾出现在聊天记录里，**建议立即轮换**，并通过 `.env`（已被 gitignore）注入，绝不放进程参数。
- [ ] 增加基础的**请求日志 + 错误监控**（目前完全无日志），否则上线后无从排查。

## 二、🟠 高优先级：部署与可运维性

| 缺口 | 现状 | 建议 |
|---|---|---|
| 进程守护 | `node server.cjs` 前台裸跑，崩了即停 | PM2 / systemd / Docker 重启策略 |
| 配置管理 | 端口、监听地址、数据目录硬编码 | 全部走环境变量 / 配置文件 |
| HTTPS | 无 | Nginx/Caddy 反向代理 + 证书 |
| 数据持久化 | JSON 文件 + 内存会话 | 短期可保留（单机内网够用），长期迁移 SQLite/PostgreSQL |
| 备份 | 无 | 定时备份 `.local-data/`（含录音与账号） |
| 日志轮转 | 无 | 接入 stdout + 采集器 |
| 构建产物 | `dist/` 在 gitignore，`server.cjs` 直接读 `public/` | 上线需明确"构建 vs 源码"部署路径，当前有 `dist/` 与 `public/` 并存的历史包袱 |

## 三、🟠 高优先级：功能缺口（对乡村场景最要紧的）

### 3.1 多首歌支持（P0 杠杆最大）

- 现在**只有《茉莉花》**接了真实 Agent 与真实测量，其余是模板演示。乡村音乐课要落地，必须能录入任意曲目并复用同一管线。
- 简谱导入流水线（`import-pipeline.cjs`）已能解析任意手抄简谱，但测量/AI 备课仍锁定《茉莉花》。**把测量和 Agent 从"茉莉花专用"泛化到"任意 lesson id"** 是投入产出比最高的一步。

### 3.2 多人 / 全班混唱分析

- ~~现状：`context !== 'single'` 直接判无效~~ → **2026-09-20 已实现建议的第一步**：`analyzeGroup()` 输出全班整体概览（整体音高中心 + 离散度、能量包络速度、起音对齐离散度），group 专用决策，UI 有「多人 / 全班齐唱」场景选项；混唱无法分离个体，全程如实声明"不推断任何单个孩子的表现"（测试基线 110 → 111）。
- 剩余：全班齐唱的逐次对比与班级级汇总报表；单源分离（第二步）仍未做。

### 3.3 音准算法升级（DTW + pYIN）

- 现状用归一化自相关 + 保守顺序对齐，多音/连音即判"无法对齐"。
- 对学生跑调、拖拍、连音是常态的乡村场景，DTW 能显著提升鲁棒性，pYIN 能更稳地估基频。

### 3.4 儿童端 / 课堂大屏

- 文档明确"儿童端未做"。乡村课堂上，学生需要**一个更大的、更直观的界面**（大字、大按钮、跟随高亮），教师端之外的第二屏是刚需。

### 3.5 弱网 / 离线模式

- 乡村学校网络是最大不确定性。当前无 Service Worker、无端侧分析、无降级。**至少要做"页面离线可浏览课件 + 明确降级提示"**。

## 四、🟡 中优先级：体验与细节

- **Google Fonts CDN**：`style.css` 第一行 `@import fonts.googleapis.com`——**国内基本不可访问**，会拖慢首屏甚至字体加载失败。虽有 `'Microsoft YaHei'` 兜底，但建议**移除外链或本地化字体/换系统字体栈**。
- **首屏与静态资源缓存**：`Cache-Control: no-cache` 全站生效，WAV 资源每次重新下载。上线应对 WAV/PNG 等静态资源做长缓存 + 内容指纹。
- **无障碍**：已有 `:focus-visible`、`aria-live` 等，做得不错；可补语言朗读（`speechSynthesis` 依赖浏览器，可保留兜底）。
- **多语言/方言**：乡村教师可能用方言，TTS/ASR 仍是浏览器兜底，准确率不可控——列为已知边界即可，不必上线前强求。

## 五、✅ 已做得很好的部分（保持，别破坏）

1. **诚实声明贯穿全链路**："合成音非真人范唱""测量不代表真人教学已验证""无来源即不输出"——这在教育 AI 产品里是稀缺的可信度资产。
2. **零第三方依赖**：原生 `http` 模块 + 手写 OOXML PPTX/CRC32/BM25/共振峰合成，无供应链风险，部署极简。
3. **账号隔离 + scrypt + HttpOnly + 限流 + 来源校验**：认证链路基础扎实。
4. **版权闸门**：来源未登记即拦下、不排课不合成，对"音乐内容版权"这个上线雷区有清醒处理。
5. **106/106 测试全绿**，覆盖测量/账号/Agent/导入/课件/报告。
6. **可追溯**：录音 SHA-256、来源 ID、逐条 verifiedBy、报告只统计有效样本——数据可信度工程到位。

## ✅ 建议的上线路线（分三档）

| 阶段 | 目标 | 关键动作 |
|---|---|---|
| **第 1 档（内网试教）** | 1 所学校、教师单机/局域网 | 进程守护 + 录音自动删除 + 隐私告知 + 多首歌泛化 + 移除 Google Fonts |
| **第 2 档（单点公网）** | 小范围公开、可控用户量 | Docker + PM2 + Nginx HTTPS + Secure Cookie + X-Forwarded-For 限流 + 日志/备份 + SQLite |
| **第 3 档（规模上线）** | 多校并发、正式运营 | PostgreSQL + 对象存储(录音) + 多人混唱 + DTW/pYIN + 儿童端 + 儿童数据合规评估（可能需要实名/备案/等保咨询） |

## ⚠️ 待确认 / 假设 / Non-goals

- 假设上线主体是**教育/公益性质**（比赛、试点），不涉及商业变现——若涉及收费，需额外评估 ICP 备案、增值电信业务许可。
- 假设用户量级先到"单校试点"而非"全国并发"——若直接面向公众，架构需整体重估。
- Non-goal：本文不评估商业模式、不评估音乐版权采购（版权闸门已兜底，但正式上线仍需逐曲目确认授权）。
