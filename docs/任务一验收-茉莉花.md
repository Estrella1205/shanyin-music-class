# 任务一验收｜《茉莉花》成为可验证的教学对象

日期：2026-09-12。对象编号：`molihua-opening-v1`，版本：`1.0.0`。

## 选定版本，而不是混用“通用茉莉花”

谱源为[湖南艺术职业学院公开的专业技能考核标准及题库](https://jwc.arthn.com/__local/7/B3/83/3107CEF266DCC87041DDD41E5CA_A3C890B5_1DAFB6.pdf#page=30)，PDF第30页、印刷页27，“试题2-6”中的江苏民歌谱例。已渲染并逐音查看第一行前两小节。

该谱例明确标注 **1=E、4/4拍**。本项目固定以这两个小节为参考，不再把原先方案的2/4拍套在这版上；这也不意味着其他版本的2/4记谱错误。

本地教学参考移调为 **1=C**，下降4个半音，保持相对音程与记谱时值。音域为E4至C5。**80 BPM标准速度和60 BPM慢速由项目设定**；原谱只给出文字速度表情，没有这两个数值。本任务不声称这个音域或速度已经过班级试教验证。

## 已校对的短乐句

两小节共8个四分音符拍、11次发音。第5、6音都是C5，应分别发音，不能漏掉一个；最后一个G4持续2拍。

调律基准：A4=440Hz，十二平均律。频率值由MIDI音高计算；表中时间不含预备拍。原谱的两处连音分组已在数据中记录，但电子音参考未复现唱腔、强弱和表情。

## 可直接使用的交付物

- `dist/lessons/molihua.lesson.json`：唯一原始数据，包含谱源、移调、每个音、时值、音频参数、学习目标、教学条件与活动。
- `dist/lessons/lesson.schema.json`：JSON Schema；`dist/lesson-core.js`执行总拍数、音符连续性、移调和课程约束等校验。
- `dist/assets/audio/molihua-c-80.wav`：标准参考，乐句6秒，另有0.25秒静音尾部。
- `dist/assets/audio/molihua-c-60.wav`：慢速参考，乐句8秒，另有0.25秒尾部。
- `dist/assets/audio/molihua-c-80-countin.wav`：4拍预备3秒 + 乐句6秒 + 尾部0.25秒。
- `dist/lessons/audio-manifest.json`：三个文件的速度、预备拍、时长和SHA-256，关联原始数据摘要。
- `dist/lessons/molihua-plan-example.json`：四年级28人、40分钟、无钢琴的实例计划。
- `build-lesson.cjs`：从原始数据重新生成音频、浏览器数据与实例计划。
- `lesson.test.cjs`：谱面独立转录基准、课程条件变化、实际PCM波形与数据一致性检查。

这些WAV是本项目合成的电子音参考，不是真人范唱，不来自第三方录音。为便于听辨，音符发声占记谱时长的92%，余下为轻微分离；后一个音的起点保持谱面时值，不会越唱越快。全谱PDF只作本地查阅，位于忽略的research目录，不随网页提供下载；谱面没有标明开放许可证，公开使用前仍须明确相关使用权限。

## 课堂计划可验证

三个目标：保持8拍稳定节奏；辨认并模唱上行和重复高音；区分半拍与末音两拍。目标关联到每个活动，并有教师观察点，不能用当前预设评分证明达标。

默认40分钟分配：热身5、四拍律动7、参考聆听5、分句模唱10、录音观察6、针对性练习5、小结2分钟。

- 时长：10–90分钟整数范围均分配7个正整数时长，合计严格等于课堂总时长。
- 人数：≤24人采用两人互听；>24人按每组最多7人安排轮流练习。录音仍要求一次只选一人，不将混唱当作个体评价。
- 设备：无钢琴使用电子音参考和拍手；有钢琴则提示教师示范同一个C调乐句。
- 年级：低年级以高低手势和模唱为主，其他年级加入简谱与时值认识；已有基础的班级增加独立尝试。
- 教案保留“从自然声音开始”和“复习阶梯音”的输入联动。

《小雨沙沙》《两只老虎》继续保留原有模板演示，但没有被标记为完成同等级谱面校对。

## 已通过的验证

执行：`node --test lesson.test.cjs`。

1. 独立转录基准核对11个音高、11个时值、起点和两个完整4/4小节；错误时值会触发失败。
2. 10–90分钟全部81种时长，搭配4种人数共324个组合，总时长与正整数环节检查通过；人数、设备、年级的变化确实影响活动。
3. 直接读取三个WAV的PCM波形，逐音用过零周期估计频率；全部与预期相差小于1音分，发音起点误差小于10ms。检查了声道、采样率、位深、尾部静音及无削波。
4. 文件摘要与教学数据一致；页面简谱、表格和播放由同一份数据驱动。

本次完成的是**谱面校对、可重建音频、结构化课程和程序验证**。尚未完成专业音乐教师试教审定、真实录音音准/节奏检测、真实Agent推理及学习效果验证。后续任务应在这个稳定对象上继续，而不是换一套音符或预设分数。
