# 开源音乐资源核查报告

核查日期：2026-09-13
用途：为「声入山野」寻找可合法使用的歌曲、乐谱与权威来源

---

## 一、直接回答：网上有没有"开源歌曲"

"开源"在这里其实是三个不同的问题，必须分开答：

| 问法 | 结论 |
|---|---|
| 有没有可直接再分发的**中文儿歌数据集**（词 + 曲 + 乐谱）？ | **没有**。查遍公开数据集，不存在 |
| 有没有**已进入公有领域的中文歌曲**（可自己记谱合法使用）？ | **有，而且不少。这是最实用的路径** |
| 有没有**开源乐谱库**？ | **有且质量高**：PDMX（25 万首 MusicXML）、OpenScore（CC0） |

**核心判断：不要去找"开源歌曲"，要找"已进入公有领域的作品"，然后自己记谱。**

理由：著作权保护的是**特定人的记谱 / 编配版本**（针对传统民歌）或**词曲作者的创作**；词曲作者逝世满 50 年的作品，词曲本身已进入公有领域，任何人都可以重新记谱使用，且**新记谱版本归你**。

这条结论比"找到一份免费乐谱"更值钱，因为它同时解决了法律风险和资源的可持续性。

## 二、资源清单（含许可判定）

### A 类 · 中文公有领域歌曲 —— 法律最干净，强烈推荐

中国《著作权法》：保护期为**作者终生 + 死后 50 年**，届满于死后第 50 年的 **12 月 31 日**。**词、曲分别计算，两者都届满才能整体使用。**

| 作品 | 词作者 | 逝世 | 词进入 PD | 曲作者 | 逝世 | 曲进入 PD | 整体可用 | 核验 |
|---|---|---|---|---|---|---|---|---|
| **《小兔子乖乖》**（原名《老虎叫门》，出自儿童歌舞剧《神仙妹妹》） | 黎锦晖 | 1967-02-15 | 2018-01-01 | 黎锦晖 | 1967-02-15 | 2018-01-01 | ✅ **可用** | ✅ 百度百科 |
| **《送别》** | 李叔同 | 1942 | 1993-01-01 | J. P. Ordway（*Dreaming of Home and Mother*, 1851） | 1880 | 已届满 | ✅ **可用** | ✅ 维基文库标注 PD |
| 《卖报歌》 | 安娥 | 1976-08-18 | **2027-01-01** | 聂耳 | 1935 | 1986-01-01 | ⏳ **暂时不可用** | ✅ 百度/搜狗百科 |
| 《踏雪寻梅》 | 刘雪庵 | 待核验 | — | 黄自 | 1938 | 1989-01-01 | ❌ 词在保护期 | ⚠️ 年份待核验 |
| 《西风的话》 | 廖辅叔 | 待核验 | — | 黄自 | 1938 | 1989-01-01 | ❌ 词在保护期 | ⚠️ 年份待核验 |
| 传统民歌（《茉莉花》《小放牛》《沂蒙山小调》《小白菜》等） | 无特定作者 | — | — | — | — | — | ✅ **曲调可用，须自己记谱** | — |

**三个关键结论：**

1. **《小兔子乖乖》是唯一同时满足「中文 + 儿歌 + 词曲均 PD + 家喻户晓 + 结构极简」的曲目。** 黎锦晖被誉为"中国儿童歌舞剧之父"，此曲 1920 年创作，词曲均出自他一人之手，1967 年逝世、2017-12-31 保护期届满。**这就是首选的第二首歌。**

2. **《卖报歌》是个绝佳的边界案例**：曲（聂耳，1935 卒）早已公有，但词（安娥，1976-08-18 卒）要到 **2026-12-31** 才届满——**现在收录歌词是侵权的，2027-01-01 起才合法**。这种"差 3 个月"的判断，靠人工审查一定会出错，**只能靠机器闸门**。这是上一版方案里"版权闸门"必要性的最有力证据。

3. **传统民歌是最大的资源池**：曲调世代流传、无特定作者，不受著作权保护。风险只在于"用了别人的记谱 / 编配版本"。**自己记谱就完全规避**——这正好落在上一版方案设计的「山野简谱文本」工具内。

4. **但"作品已公有"不等于"谱子能拿来用"——这是一个必须讲清楚的落差。**
   以《小兔子乖乖》为例：词曲的公有领域状态已被闸门确认（黎锦晖 → 2018-01-01 起 PD），但**音符级的旋律拿不到可核验来源**。实测情况：
   - 第三方简谱站（简谱之家、爱弹琴、琴谱123、tanqin123）全部是"免费下载但未标许可"，只能 link-only，**且各家版本互相矛盾**；
   - 百度文库某份《小兔子乖乖》简谱解析文档里，**同一文档内两处记谱就不一致**（一处 `1 1 5 5`，另一处 `5 5`）；
   - tanqin123 某条署名"黎锦晖,王忠勤"——这是**改编版**，不属公有领域；
   - 该曲确实是**花城版/辽海版一年级上册第 12 课**的教材曲目，但配套资源在受版权保护的教辅平台上。

   所以本项目**没有**录入该曲，因为按 `AGENTS.md`「绝不把模拟结果表述为测量」，用互相矛盾的第三方版本或凭记忆凑出的旋律写进课程数据，就是造假。**解除阻塞最可靠的途径是教师本人手上的教材版本**——她就是这个版本的权威。

### B 类 · 开源乐谱数据集（格式直接可用）

| 资源 | 许可 | 规模与内容 | 与项目的关系 |
|---|---|---|---|
| **PDMX** `github.com/pnlong/PDMX` / Zenodo `15571083` | 数据集标注为 public domain 乐谱 | **25 万+ 首 MusicXML**，抓取自 MuseScore 公有领域内容 | 格式正好是我们要的 MusicXML；**但见下方警告** |
| **OpenScore** `fourscoreandmore.org/openscore/` | **CC0**（主动放弃权利，可自由复制/修改/分发/商用） | 艺术歌曲约 1300–1500 首、弦乐四重奏约 700 乐章、管弦乐约 100 乐章；提供 `.mscz` + `.mxl` | 直接支撑决策 3「音乐与土地 / 音乐家」模块，作品谱例有合法来源 |
| **Mutopia Project** `mutopiaproject.org` + GitHub `MutopiaProject/MutopiaProject` | 基于公有领域版本 | LilyPond 源文件 + PDF，可 git clone | 可作为乐谱层的补充源 |
| `musetrainer/library` | GitHub 标注 Public domain MusicXML | 规模小 | 本轮抓取超时，**许可需人工确认** |

**⚠️ PDMX 的重要警告（必须写进方案）**：
PDMX 官方 README 明确指出，MuseScore 网站公开展示的版权元数据与文件内部版权数据**存在不一致**，影响 **12.29%（31,221 首）** 的曲目。项目方建议**只使用 `no_license_conflict` 子集**，并把冲突记录在 `license_conflict` 列。

这说明：**即使是标着"公有领域"的数据集，元数据也不能全信。** 任何引入的曲目都必须经过我们自己的核验，不能直接信任上游标签。

另需注意：PDMX 语料以西方古典为主，**中文曲目极少**，且 README 未声明是否保留歌词。

### C 类 · 权威中文音乐来源（可引用，不可抓取）

| 资源 | 权威性 | 许可判定 |
|---|---|---|
| **中国传统音乐录音档案数字平台** `www.ctmsa-cnaa.com` | **最高**。中国艺术研究院建设，7000 小时录音，1997 年入选联合国教科文组织《世界记忆名录》——**中国首个入选项目、世界首个入选的音响档案**。免费开放，含**民间歌曲 2234 条**、民族器乐曲 1148 条等 | 定位为"公益性音频资源数字平台"→ **link-only**。可作权威来源指引与核验依据，**不可下载再分发** |
| 中国音乐著作权协会 `mcsc.com.cn` | 官方集体管理组织 | 需商用授权时的正规渠道，非素材源 |
| 国家图书馆「民国时期文献」/「中华古籍资源库」 | 高 | 民国出版物多已进入公有领域，可作乐谱与歌词的**核验依据**；具体条目的数字化状态需逐项确认 |

**「中国传统音乐录音档案」对乡村音乐课的意义**：它收录的正是各地民间歌曲的原始田野录音。用它来核对一首民歌的**流传地、方言、演唱场景**，比任何百科都权威——这恰好是决策 3「音乐与土地」模块最需要的素材。但只能作**来源指引**（老师点击跳转去听），不能嵌入。

### D 类 · 明确不推荐（避坑）

| 资源 | 问题 |
|---|---|
| MuseScore 网站直接抓取 / LibreScore / musescore-downloader | 存在绕过付费机制的问题；且版权元数据不可信（PDMX 的 12.29% 冲突率即证据） |
| 简谱之家、爱弹琴、琴谱123、弹琴吧等 | **"免费下载"不是许可**。未标明可再分发 → 只能 link-only，**绝不能**把谱面写进课程数据 |
| Musopen `musopen.org` | 本轮抓取被 Cloudflare 安全验证拦截，**许可未能确认**。使用前必须人工打开具体乐谱页查看 License 标识 |
| 各类"儿歌大全"网站 / 短视频平台歌词 | 无许可信息，且多为未授权转载 |

## 四、怎么用：三种集成方式

**必须明确一点：不要把外部乐谱库做成运行时依赖。** 项目是零依赖、本地运行的，运行时联网抓取既不可靠也不可控。

| 方式 | 做法 | 适用 |
|---|---|---|
| **① Vendored 固化（推荐）** | 人工核验后，把乐谱以 JSON 形式写入仓库，每个文件带 `sourceId / 许可 / 核验人 / 核验日期 / sha256` | A 类公有领域曲目、B 类开源数据集 |
| **② 自研记谱** | 用「山野简谱文本」自己录入传统民歌 | 传统民歌（最干净、可持续） |
| **③ link-only 指引** | 数据里只存 URL + 标题 + 抓取时间 + 哈希，UI 上以"来源卡片"呈现 | C 类权威平台 |

**明确不做**：运行时从 MuseScore / 简谱站 / 数据集仓库自动抓谱。

## 五、决策确认（你已答复的四点）

| # | 你的决定 | 对方案的影响 |
|---|---|---|
| 1 | 没有教材，从网上找开源歌曲 | 走 **A 类公有领域作品 + 自研记谱**；B 类开源数据集作补充；**放弃"找现成中文儿歌数据集"** |
| 2 | 可以引入外部程序 | **P4 视频档 1 解锁**：课件 + TTS 旁白 + ffmpeg → MP4。需在 `package.json` 加可选依赖说明，并保留无 ffmpeg 时的自动降级 |
| 3 | 不止做音乐家，可以扩展 | 模块正式定为 **「音乐与土地」**：既装音乐家生平，也装"这首歌从哪来"（流传地、方言、劳动场景）。数据模型通用 |
| 4 | 不出现学生信息 | 课件、报告、视频中均不出现学生姓名与照片；沿用现有 `.local-data/` 本地边界 |
