# 任务三、四：单人短乐句检测与复测

本次范围：安静环境、一位演唱者、无伴奏，C调《茉莉花》开头两小节，80 BPM。不向模型服务发送录音，不需要模型密钥。录音保存在本机登录账号下。

## 使用

1. 启动 `node server.cjs`，登录，进入《茉莉花》的“AI听唱”。
2. 先听参考，再停止播放；单人清唱，重复音轻轻分开。录制或上传1–20秒单声道音频。
3. 结束录音后，浏览器解码并重采样为16kHz、16位单声道PCM WAV，交给本机后端分析。
4. 查看偏差位置、偏高/偏低、音分、可信度、起音误差及无效原因。点击“开始所选练习”。
5. 点击“使用第二次录音复测”，录制或上传另一份音频。系统重新运行完整检测，再比较两份实际指标。原音频和结果不覆盖。
6. “我的测量记录”可恢复历史。结果页可回听、下载两次WAV并导出测量JSON。

不要录入学生姓名等身份信息。采样文件留在 `.local-data/audio-attempts/`，由账号权限保护，不在静态资源目录中。每次记录包含音频SHA-256、录音ID、前次ID、时间、算法版本、教学对象版本、质量、逐音指标、策略与比较。练习按钮只记录“请求执行”，不声称知道学生是否练习完成。

## 算法与边界

- 质量先行：RMS低于0.003判静音/过低；绝对振幅超过0.985的样本占比超过1%判削波。声学活动帧中可靠周期帧不足65%判无效。
- 基频：40ms窗、10ms步长，100–800Hz范围，归一化自相关局部峰、抛物线插值。不是神经网络模型，也不声称完整实现YIN。自相关用于基频估计的研究背景：[de Cheveigné 与 Kawahara，2002](https://pubmed.ncbi.nlm.nih.gov/12002874/)。
- 音符转换：频率转换为连续MIDI与音分，用能量间断及持续音高变化分段，段内中位数抑制局部抖动。
- 对齐：保守的顺序一一对齐，需要11个清楚的稳定音段。缺音、多音、连唱重复音边界不清会判无效，不做强制补音或满分对齐。稳定段不足70ms会舍弃。
- 音准：每个音与固定参考MIDI比较，35音分为当前偏差阈值。输出绝对音高误差，不以节奏或主观音色替代。
- 节奏：独立从音段起点估计整体速度比例，扣除起唱延迟和整体速度后计算起音误差。当前不评估复杂切分、装饰音、唱腔和表情，也不对音尾延长单独评分。
- 可信度：周期性与有效覆盖率的启发值，未经真人数据概率校准。声学结果不能推断气息、心理或唱法原因。
- 多人场景直接拒绝个人测量；算法本身无法可靠自动鉴别全部混唱/伴奏。用户必须如实声明场景。单周期噪声、强伴奏、泛音主导、八度错误等仍可能误导检测，需教师判断。

## 决策与比较

优先顺序：质量或对齐无效→重录；速度偏差超过10%或去速度起音误差超过0.10秒→节拍；至少5个音超35音分→慢速；其余局部偏差→阶梯音；阈值内→巩固。阶梯音使用实测偏差位置对应的参考音及相邻音。

比较分别显示音高误差、速度偏差、节奏误差的前后值和改善/退步/无明显变化。变化阈值分别为5音分、0.03速度比例、0.02秒。任一次无效不判断进步；相同音频SHA直接拒绝复测。不同SHA只说明文件不同，不证明是新的现场演唱。

## 可复现验收

运行 `node --test audio.test.cjs agent.test.cjs auth.test.cjs lesson.test.cjs`。

在PowerShell设置 `$env:EXPORT_AUDIO_FIXTURES='1'` 后执行上述命令，还会生成 `test-results/audio-acceptance/` 下的WAV、逐项JSON和汇总manifest。测试音序与节奏独立手工录入，不调用生产参考合成器。

| 输入 | 预期 |
|---|---|
| 标准合成音 | 有效、平均音高误差小于8音分、速度接近80 BPM、原句巩固 |
| 整体偏低100音分 | 检出约−100音分、节奏仍正常、慢速模唱 |
| 第5音偏低100音分 | 定位第5音偏低、阶梯音练习 |
| 速度加快25% | 音准仍正常、速度约100 BPM、节拍练习 |
| 静音 | 无效，无音准总体指标，要求重录 |
| 固定种子白噪声 | 周期性不足，无效，要求重录 |
| 标准→偏低 | 如实显示退步 |
| 相同指标比较 | 无明显变化 |
| 削波、短残句、格式损坏、多人声明 | 拒绝可靠测量或拒绝输入 |

自动化还验证账号隔离、两次原音频保存、复测关联、重复音频拒绝及重启后读取。合成样本通过不等于真实儿童演唱已验收；当前未进行真人试唱准确率、噪声鲁棒性或群体公平性评估。
