## 二、P0 关键功能缺口（直接影响核心闭环）

- [ ] **首页自然语言解析 + 缺失信息追问**
  - 现状：`dist/app.js` 的 `parseRequest()` 仍用正则提取年级／人数／时长／歌曲／设备
  - 缺口：条件缺失时的追问与失败兜底未实现；模型解析仅存在于 Agent 任务内部（requirements schema）
  - 验收：输入模糊需求时能追问缺失字段并给出可执行解析结果

- [~] **多首歌支持**
  - 现状：仅《茉莉花》接真实 Agent 与真实测量；`teaching-agent.cjs` 对非茉莉花直接返回 `UNSUPPORTED_LESSON`
  - 缺口：《小雨沙沙》《两只老虎》仍是模板演示
  - 验收：新增任一首歌时可复用同一套 Agent／测量管线

- [ ] **Agent 工具链补全（文档 6.1 的 8 个工具）**
  - 现状：只实现 `parse / local.search / plan` 三步
  - 缺口：`analyze_singing`、`diagnose`、`choose_training`、`generate_feedback`、`generate_class_report` 未纳入 Agent 编排
  - 说明：诊断与策略目前是 `audio-analysis.cjs:decide()` 的独立规则，不产生 Agent 事件日志
  - 验收：检测→决策→反馈→报告全部在 Agent 任务事件中可见

- [~] **任务取消／重试／恢复（文档标注 P0）**
  - 现状：取消与重试已实现（状态 `cancelled`、`retryOf` 关联、事件日志保留）
  - 缺口：**断点恢复**未实现；取消只停止任务推进，已发出的模型请求无法强制中断（其结果被忽略）
  - 验收：任务可取消、可重试，状态与事件日志一致 ✅；断点续跑待补

- [ ] **Pitch 算法升级：DTW + pYIN（文档 8.3 / 8.4）**
  - 现状：`audio-analysis.cjs` 用归一化自相关求基频 + 保守顺序一一对齐
  - 缺口：**未实现 DTW**，未使用 librosa / pYIN；出现多音或连音即判"无法可靠对齐"
  - 验收：允许合理的时长伸缩与重复音，仍能输出对齐结果

- [ ] **问题类型覆盖（文档 9.2 六类）**
  - 现状：`decide()` 仅 5 条规则（无效重录／节拍练习／慢速模唱／阶梯音／原句巩固）
  - 缺口：`descending`（下行音）、`rhythm_unstable`、`long_note_short`、`repeated_failure`、`repeated_success` 未覆盖
  - 缺口："声音爬山／滑梯"仅是文字提示，无交互式训练
  - 验收：六类问题均可被识别并对应到具体训练

- [x] **课堂报告接真实数据（文档 Page 5，MVP 完成定义卡点）**
  - 现状：已新增真实测量报告中心；演示记录单独标注，不再与真实数据混在一起
  - 剩余：多人/全班报告仍是聚合不了的（依赖上面的多人分析）

- [~] **多人 / 全班混唱分析**
  - 现状：`audio-analysis.cjs` 对 `context !== 'single'` 直接判无效
  - 说明：文档允许"未实现前不伪装"，属已知边界，但功能本身未做
