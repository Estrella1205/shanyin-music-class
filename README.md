# 山音AI课 · 第一版网页 Demo

切入点：为缺少专业音乐教师和钢琴设备的乡村小学提供可执行的音乐课堂。

## 运行

直接双击 dist/index.html 即可体验主要流程。要使用麦克风，请安装 Node.js 后在本目录运行 `node server.cjs`，打开 http://127.0.0.1:4173。也可将 dist 目录发布到任意静态网站服务。

## 演示流程

1. 首页填写或沿用课堂条件，点击开始 AI 备课。
2. 观察条件解析、模板匹配、策略选择及时间分配。
3. 打开课堂时间轴，开始上课，播放电子音旋律与节拍。
4. AI听唱 → 使用示例演唱 → 针对性训练 → 再次检测（示例）。
5. 保存课堂报告，下载文本报告，或按建议准备下一课。
6. 我的班级支持本地新增；山野声音支持合成音效及课堂导入。

## 实现范围与限制

这是无依赖的 HTML/CSS/JavaScript 交互原型。备课采用规则解析与三个内置歌曲模板；不调用大模型或 RAG。音准、节奏和复测结果均为明确标注的预设示例，不能代表真实教学效果。实际录音通过 MediaRecorder 在本地录制并回放，不上传、不评分，刷新后丢失。电子音与自然模仿音效由 Web Audio 合成。语音输入依赖浏览器 SpeechRecognition，其可用性和联网要求由浏览器决定。

班级、课堂计划和示例报告保存在当前浏览器 localStorage。不要填入学生隐私信息。报告下载为 TXT，本版未制作比赛用 PDF 应用方案或 MP4 视频。

## 后续正式版本

用后端大模型将自然语言转为经过校验的课程参数；教学知识检索使用可追溯来源；音频工具进行基频、起音与参考旋律对齐；策略模块根据测量结果选择练习；用真实复测验证效果。API 密钥应仅保存在服务端。
