面向乡村小学音乐教师的备课与课堂工具：用一句自然语言描述需求，生成可执行的音乐课方案；课堂上用真实音频测量学生的音准与节奏，并沉淀成可追溯的课堂报告。

**🔗 在线预览（GitHub Pages，无需安装）**：<https://estrella1205.github.io/shanyin-music-class/>
打开就能用：备课、AI 听唱录音测量、课堂报告、简谱导入（含 MusicXML / MIDI）都能跑完；当前本机迭代版已停用注册登录界面，无需账号。

没有本地服务时，页面会自动切到**浏览器端后端**（`public/static-backend.js`）：录音测量、课堂报告、诊断、简谱导入调用的是与服务端**同一份算法**（`public/vendor/shanyin-vendor.js` 由 `server/*.cjs` 原样打包而来，`tests/browser-vendor.test.cjs` 逐字段比对二者结果），所以线上与本地给出的音分是同一个数。账号与录音只保存在你自己的浏览器里，不上传、不出设备；界面照实标注「浏览器账号」。

只有**课件生成 / MP4 合成**仍然需要本机服务 —— 它要读仓库内的音乐家生平材料并调用本机的 ffmpeg 与 Microsoft Edge，纯静态托管做不到，线上会如实说明而不是给半成品。

本地 `npm start` 打开 <http://127.0.0.1:4173> 时行为与此前完全一致（有服务端就走服务端，浏览器端后端不插手）。

- 前端：原生 HTML/CSS/JS（无构建步骤），入口 `public/index.html`
- 后端：Node.js 原生 `http` 模块，零第三方依赖
- 存储：本地 JSON + WAV 文件（`.local-data/`），按账号隔离

## 曲库课堂（并入原站 UI · 个人本机使用）

入口：主站 `public/index.html` 顶部导航的「**曲库课堂**」，或直接打开 `index.html#studio`。**双击 `index.html` 就能用**（`file://` 下完整可用，不需要服务、不需要联网），也可 `npm start` 后访问 <http://127.0.0.1:4173/#studio>。这一模块**不部署、不推送、不上传任何数据**。

- **原站 UI 保持不变**：首页、今日课堂、AI听唱、课堂报告、我的班级、山野声音的页面结构、插画、配色与组件全部原样，只在导航新增一项；课堂页复用原站 header/footer 与 `panel / btn / tabs / badge` 组件，样式限定在 `#studio-root` 内，不覆盖主站任何全局样式。`public/ai-music-class.html` 已降级为跳转到 `#studio` 的兼容入口，不再有第二套界面。
- **免登录迭代版**：注册／登录／找回密码／切换账号等界面与流程已整体停用，打开即用；启动时静默使用固定的本机账号，让录音测量、课堂报告等按账号隔离数据的功能仍可测试。服务端认证实现保持原样，日后需要账号体系时恢复前端认证界面即可。

按教学流程分两条线：**备课线**（曲库挑歌 → 备课参数 → 一键备课 → 我的备课）和**上课线**（上课演示：选班级、选已备好的课 → 六环节控制台：背景故事 → 逐句学唱（含乐理小游戏）→ 范唱·预备拍（四档音色）→ 唱一唱评分（课堂内录音）→ 卡拉OK 与小鸟飞走；课件可随环节双向联动）。曲库课堂里仍保留逐句/评分/舞台的精修视图，也能点「试教一下」临时上一遍，流程如下：① 输入歌名 → 曲库匹配 → **10 秒试听**确认曲目；② **本节课教案** + 自动生成作者/创作背景；③ **逐句拆解**（音调、演唱注意事项、停顿/换气、休止音、配套乐理知识）；④ **上课小课件**（章节 / 故事 / 逐句 / 乐理 / 小游戏，可全屏放映、可导出独立 HTML）与 **纯伴奏 / 带人声范唱 / 慢速范唱**（人声是声门源＋共振峰合成，可切清亮童声/温柔女声/温暖男声/轻柔四种音色）+ **0–8 拍可设预备拍** + 逐句录音评分（逐字问题位置、偏高偏低音分、改进方向、音高曲线）；⑤ 游戏化舞台（星星、连击、徽章、卡拉OK高亮，**最后一个歌词变成小鸟飞走**）。右上角「上传我的音频」会把一段清唱自动拆成音符、乐句与教学数据，进入同一套流程。

### 课后总结（#summary）

上完一节课，评分记录会自动收成一份小结：唱得最好的 1–2 句、最需要再练的 1–2 句、这一节的音准与拍点问题，以及 2–3 条下一节课能直接照做的建议。可以打印、导出独立 HTML 给家长，也能一键「再上一次这节课」回到对应备课包。没有录音时给童趣空态，不报错。

**拆解过程趣味化**：备课（今日课堂 → AI 备课）与「上传我的音频」拆解都不再出现技术执行日志、JSON「细节」、工具名/状态标签、来源 ID、谱源链接、任务与模型标识、免责声明；统一换成一朵**小花生长的动态进度条**——种子 → 发芽 → 长叶 → 花苞 → 开花，配沿进度条移动的小蜜蜂、蝴蝶、光点、百分比与童趣文案。进度由服务端真实完成的阶段驱动，不虚报。备课页右侧的开发核对栏改成「上课小锦囊」（今天唱什么、给谁上、多长时间、三个小提醒）。`public/grow-progress.js` + `grow-progress.css` 是共用组件，样式只作用于 `.gp-card` 内。

**课堂环节拆解（教案）**：确认歌曲后，第 ② 步先给出整节课的流程表——导入试听 → 背景故事（可直接照着讲的故事讲稿、课堂提问、要带的教具）→ 逐句学唱 → 范唱与 4 拍预备 → 逐句评分纠正 → 完整演唱与趣味收尾，共 6 个环节。环节与时长由谱面数据确定性推导（句数、音符数、BPM、4 拍预备约几秒、背景条数、休止与换气处、乐理知识点），按一课时 40 分钟估算；超过 40 分钟会建议拆成两课时。每环节写明目标、老师做什么、学生做什么、在页面哪一步操作，可展开查看数据依据与对应乐理点，「复制教案文本」可贴进备课笔记。时长是可按班级情况调整的估算值，不是课标规定值；还没有逐句谱面的曲目，逐句及之后的环节会写「待补录音」，不编造谱面。

| 位置 | 作用 |

**准确性边界（重要）**：只有 8 首带已核对谱面的曲目能直接上课，其余 70 首只给元数据、背景和故事，页面写「上传一段录音，就能逐句教」或「上传 demo 自动整理」，不编造简谱。年级索引只来自人工整理的教材曲目清单与公开音乐常识，逐条标注“有不同说法”的条目；不下载受版权保护的音频或曲谱，浏览页面不联网。自动拆解结果的调号、速度、分句是**推测**，且不做语音识别、不生成歌词，全部标「需老师核对」。演唱评分是声学吻合度，不推断气息、心理或唱法原因；无效录音不产生分数。详见 `docs/AI音乐课堂-需求对照与验收.md`。

## 快速开始

```bash
npm start            # 等价于 node server/server.cjs
```

打开 http://127.0.0.1:4173 。Windows 也可直接双击 `启动声入山野.cmd`（需保持窗口开启）。

监听与访问范围由环境变量决定，不用改代码：

| 场景 | 启动方式 | 行为 |
|---|---|---|
| 本机演示（默认） | `npm start` | 只监听 `127.0.0.1:4173`，`/api` 仅接受本机 Host，严格 Origin 校验 |
| 局域网 / 公网部署 | `PORT=8080` 或 `HOST=0.0.0.0 PUBLIC_DEPLOY=1` | 监听 `0.0.0.0:$PORT`，放行反向代理域名，限流按 `X-Forwarded-For` 计数 |

公网模式下若反向代理未透传真实域名，Origin 等值校验自动让位给自定义头 `X-Shengru-Client`（浏览器跨域请求无法不经预检携带自定义头，配合 `SameSite=Strict` 会话 Cookie 防护跨站请求）。

## 使用流程

1. **备课**：打开即可在工作台用自然语言描述需求（年级、人数、时长、歌曲、设备），生成方案与「山音工作记录」。
2. **AI 听唱**：在安静环境录制一段 1–20 秒的人声，读取音准/节奏指标；同一句可复测一次，形成前后比较。
3. **课堂报告**：报告中心只汇总本账号的有效录音，可打印/另存为 PDF，或下载文字报告、JSON、WAV。
4. **导入手抄简谱 → 课程安排**：在「听唱」或课堂「方案」页点 **导入老师手抄的简谱 ↗**。按两行对齐格式粘贴（第一行音符、第二行歌词），头部写全「歌名 / 体裁 / 拍号 / 调号 / 速度」，带歌词时必须声明 `# 来源: <sourceId>`。点「解析并预览」即得到难度指标、7 环节课程安排、版权闸门裁决与合成好的参考/慢速/含预备拍音频；谱面写错会定位到具体行列。
5. **生平材料 → 课件 / 视频 / PPTX**：同页点 **生成课件 · 视频 ↗**，勾选生平材料（可多选，可选本课曲目与主题）。生成后可全屏放课件（带打印样式，可另存为 PDF）、逐张导出 1920×1080 矢量图、下载分镜脚本（Markdown）、**下载 PPTX 课件（原生文本框，PowerPoint/WPS 里可直接改字）**；本机同时具备 Edge 与 ffmpeg 时，点 **🎬 合成 MP4 视频** 一键出片（Edge 无头逐张截图 → ffmpeg 按分镜时长精确拼接，指定本课曲目时参考音频循环垫底），成片可直接在线播放或下载。

> 第 4、5 步**无需登录**：它们只读仓库内已登记的公开材料（`knowledge/`）与 `public/lessons/`，只写按内容哈希寻址的缓存，不碰任何账号数据——老师可以先试一遍，再决定要不要注册。
>
> 接口、返回字段与「免登录」的理由见 `docs/音乐资源与课件生成方案.md` §9。

## 备课工作台与联网找歌（本机迭代版）

- **备课工作台**（导航「课前备课 · 备课工作台」）：一键备好课后先进这里，不直接进课堂。左侧列出所有备好的课，右侧三页签可按需修改——📋课堂安排（环节名/时长/老师怎么做，可增删改排序）、🖼上课课件（每页标题/歌词/简谱/要点都能改，可增删排序、单页预览、整套放映，可导出独立 HTML）、🎧唱歌示范（整首与逐句范唱/伴奏试听、可换声音）。「保存修改」写回本机，「去上课」才带着这节课进课堂。投屏大屏、AI 听唱都跟随最近备/上的那首歌，不再固定《茉莉花》。
- **趣味特效**：卡拉OK 唱到最后一个字，那个字会鼓起变色再淡出、化作小鸟扑翅飞走并拖出星光——是歌词本身的动画，不是手动按钮。学生大屏有飘动的音符星星。首页/页头的小人与图标点一下会摇摆冒笑脸。
- **联网找歌（可选）**：导航「联网找歌」里有搜索框，有网时查公开曲库的歌名/歌手/封面，喜欢的可"收进我的曲库"；这里只登记介绍信息，**不下载受版权保护的音频/曲谱，也不编造逐句内容**——要逐句跟唱仍在曲库里挑带范唱的歌备课。断网时如实提示并退回本地曲库，不影响备课上课（运行时零联网依赖的基线不变）。

## 功能边界（不做的部分也写清楚）

- 《茉莉花》与《两只老虎》接入真实教学 Agent（需配置模型）与真实音频测量：在「更多条件」或首页需求里把「本课歌曲」换成《两只老虎》即可整课切换（谱面、带歌词示范、测量、Agent 备课、课件全部随课切换）。《小雨沙沙》为模板演示。Agent 备课默认联网检索公开资料补充本地校对资料（来源链接全程可追溯；断网/限流时如实记录并只用本地资料继续；`TEACHING_WEB_SEARCH=off` 可关闭）。
- 测量限定「安静环境、一位演唱者、无伴奏、1–20 秒」，多人与带伴奏录音会判为无效；声学偏差不能推断气息、心理状态或唱法原因。
- 示范与自然音效由 Web Audio 合成；朗读与语音识别依赖浏览器能力。
- 【本机免登录迭代版】前端的注册／登录／找回密码／切换账号界面已整体停用，启动时静默使用固定本机账号；下面是**底层账号体系**的说明（服务端实现保留，供日后恢复）。账号系统不含邮件/手机验证、第三方登录或跨设备云同步，服务器重启后需重新登录（数据保留）。**找回密码**用注册时发放的一次性恢复码（16 位，只显示一次、只存哈希、用过即换）：登录页「忘记密码？用恢复码找回」，或登录后到「个人资料 · 账号找回」重新生成一枚。**静态预览（GitHub Pages）下账号只存在于当前浏览器**：口令用 Web Crypto 的 PBKDF2-SHA256（120k 次）派生后存 localStorage，换浏览器或清理浏览数据后需要重新注册；注册页照实写明这一点。
- 歌谱导入除「山野简谱文本」外，还支持 **MusicXML / MIDI 文件**（在导入弹窗里选文件即可）：文件先转成山野简谱文本再走同一条流水线，老师能看见、能改、能再导出。一期只支持单旋律与 2/4 3/4 4/4；和弦、多声部、复拍子、复音 MIDI 会明确报错而不替你挑一条轨。来源未登记时版权闸门会拦下，此时**不排课、也不合成音频**，只给解析结果与拦截理由。
- 课件遵守「无来源即不输出」：引用解析不到已登记来源的句子会被丢弃并记入 `dropped[]`（前端可展开查看），整张丢空则连幻灯片一起丢；材料或来源未标 `verifiedBy` 时全程标「⚠ 待人工核对」。课件 PDF 用浏览器打印实现，无服务端 PDF；三色徽章未做。
- 视频合成是**真实**的：Edge 无头把幻灯片截成 1920×1080 PNG，ffmpeg（libx264 + AAC）按分镜时长拼接成 MP4，音频用本课参考音频循环垫底并按总时长精确封顶。Edge 或 ffmpeg 缺任一样时如实提示缺什么、怎么装，仍交付分镜脚本 + 矢量图 + PPTX——不谎称已出片。ffmpeg 探测支持 `FFMPEG_PATH` 环境变量与项目内 `tools/ffmpeg/` 副本。
- 知识库是**最小可用**的本地检索（`knowledge/` + 单字/两字词元 + BM25，零依赖、结果可解释），不是向量检索；`knowledge/songs/`、`strategies/` 尚未建。
- **弱网离线模式**：内置 Service Worker 离线外壳——外壳（HTML/CSS/JS/课程数据，约 250KB）装时缓存，参考音频等大件用到才缓存，并后台补一个最小离线包；断网时已打开过的页面与已缓存的参考音频照常可用，而录音测量、登录这些要真数据的功能会如实提示「需要连接本机服务」，不拿旧数据冒充新结果。
- **儿童大字模式**：教师端账号菜单、学生端菜单、学生大屏三处可切换（`html.big-text`），只放大字号与按钮，不动任何测量与判定；选择会被记住。
- 录音按保留期**课后自动删除**（默认 30 天，`AUDIO_RETENTION_DAYS` 可配，`0` 关闭）：到期只删音频本体，测量与诊断记录保留并如实标注「音频已删除」。
- 仍未做：端侧离线分析（测量仍在服务端）、儿童端独立交互形态、监护授权／伦理流程。

详细缺口见 `docs/功能缺口清单.md`。

## 开发约定

- 服务端与前端逻辑分离：`public/` 只放浏览器代码，`server/` 只放 Node 代码，`lesson-core.js` 为两端共用的纯算法。
- 先本地实现与验收，不擅自部署或推送线上版本。
- 测试一律使用临时目录，不读写 `.local-data/`。
