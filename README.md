# 声入山野 · AI 乡村音乐课堂

面向乡村小学音乐教师的备课与课堂工具：用一句自然语言描述需求，生成可执行的音乐课方案；课堂上用真实音频测量学生的音准与节奏，并沉淀成可追溯的课堂报告。

- 前端：原生 HTML/CSS/JS（无构建步骤），入口 `public/index.html`
- 后端：Node.js 原生 `http` 模块，零第三方依赖
- 存储：本地 JSON + WAV 文件（`.local-data/`），按账号隔离

## 快速开始

```bash
npm start            # 等价于 node server/server.cjs
```

打开 http://127.0.0.1:4173 。Windows 也可直接双击 `启动声入山野.cmd`（需保持窗口开启）。

监听与访问范围由环境变量决定，不用改代码：

| 场景 | 启动方式 | 行为 |
|---|---|---|
| 本机演示（默认） | `npm start` | 只监听 `127.0.0.1:4173`，`/api` 仅接受本机 Host，严格 Origin 校验 |
| 局域网 / 公网部署 | `PORT=8080` 或 `HOST=0.0.0.0 PUBLIC_DEPLOY=1` | 监听 `0.0.0.0:$PORT`，放行反向代理域名，限流按 `X-Forwarded-For` 计数 |

公网模式下若反向代理未透传真实域名，Origin 等值校验自动让位给自定义头 `X-Shengru-Client`（浏览器跨域请求无法不经预检携带自定义头，配合 `SameSite=Strict` 会话 Cookie 防护跨站请求）。

## 使用流程

1. **备课**：登录后在工作台用自然语言描述需求（年级、人数、时长、歌曲、设备），生成方案与「山音工作记录」。
2. **AI 听唱**：在安静环境录制一段 1–20 秒的人声，读取音准/节奏指标；同一句可复测一次，形成前后比较。
3. **课堂报告**：报告中心只汇总本账号的有效录音，可打印/另存为 PDF，或下载文字报告、JSON、WAV。
4. **导入手抄简谱 → 课程安排**：在「听唱」或课堂「方案」页点 **导入老师手抄的简谱 ↗**。按两行对齐格式粘贴（第一行音符、第二行歌词），头部写全「歌名 / 体裁 / 拍号 / 调号 / 速度」，带歌词时必须声明 `# 来源: <sourceId>`。点「解析并预览」即得到难度指标、7 环节课程安排、版权闸门裁决与合成好的参考/慢速/含预备拍音频；谱面写错会定位到具体行列。
5. **生平材料 → 课件 / 视频 / PPTX**：同页点 **生成课件 · 视频 ↗**，勾选生平材料（可多选，可选本课曲目与主题）。生成后可全屏放课件（带打印样式，可另存为 PDF）、逐张导出 1920×1080 矢量图、下载分镜脚本（Markdown）、**下载 PPTX 课件（原生文本框，PowerPoint/WPS 里可直接改字）**；本机同时具备 Edge 与 ffmpeg 时，点 **🎬 合成 MP4 视频** 一键出片（Edge 无头逐张截图 → ffmpeg 按分镜时长精确拼接，指定本课曲目时参考音频循环垫底），成片可直接在线播放或下载。

> 第 4、5 步**无需登录**：它们只读仓库内已登记的公开材料（`knowledge/`）与 `public/lessons/`，只写按内容哈希寻址的缓存，不碰任何账号数据——老师可以先试一遍，再决定要不要注册。
>
> 接口、返回字段与「免登录」的理由见 `docs/音乐资源与课件生成方案.md` §9。

## 功能边界（不做的部分也写清楚）

- 《茉莉花》与《两只老虎》接入真实教学 Agent（需配置模型）与真实音频测量：在「更多条件」或首页需求里把「本课歌曲」换成《两只老虎》即可整课切换（谱面、带歌词示范、测量、Agent 备课、课件全部随课切换）。《小雨沙沙》为模板演示。Agent 备课默认联网检索公开资料补充本地校对资料（来源链接全程可追溯；断网/限流时如实记录并只用本地资料继续；`TEACHING_WEB_SEARCH=off` 可关闭）。
- 测量限定「安静环境、一位演唱者、无伴奏、1–20 秒」，多人与带伴奏录音会判为无效；声学偏差不能推断气息、心理状态或唱法原因。
- 示范与自然音效由 Web Audio 合成；朗读与语音识别依赖浏览器能力。
- 账号系统不含邮件/手机验证、第三方登录或跨设备云同步，服务器重启后需重新登录（数据保留）。**找回密码**用注册时发放的一次性恢复码（16 位，只显示一次、服务端只存哈希、用过即换）：登录页「忘记密码？用恢复码找回」，或登录后到「个人资料 · 账号找回」重新生成一枚。
- 歌谱导入除「山野简谱文本」外，还支持 **MusicXML / MIDI 文件**（在导入弹窗里选文件即可）：文件先转成山野简谱文本再走同一条流水线，老师能看见、能改、能再导出。一期只支持单旋律与 2/4 3/4 4/4；和弦、多声部、复拍子、复音 MIDI 会明确报错而不替你挑一条轨。来源未登记时版权闸门会拦下，此时**不排课、也不合成音频**，只给解析结果与拦截理由。
- 课件遵守「无来源即不输出」：引用解析不到已登记来源的句子会被丢弃并记入 `dropped[]`（前端可展开查看），整张丢空则连幻灯片一起丢；材料或来源未标 `verifiedBy` 时全程标「⚠ 待人工核对」。课件 PDF 用浏览器打印实现，无服务端 PDF；三色徽章未做。
- 视频合成是**真实**的：Edge 无头把幻灯片截成 1920×1080 PNG，ffmpeg（libx264 + AAC）按分镜时长拼接成 MP4，音频用本课参考音频循环垫底并按总时长精确封顶。Edge 或 ffmpeg 缺任一样时如实提示缺什么、怎么装，仍交付分镜脚本 + 矢量图 + PPTX——不谎称已出片。ffmpeg 探测支持 `FFMPEG_PATH` 环境变量与项目内 `tools/ffmpeg/` 副本。
- 知识库是**最小可用**的本地检索（`knowledge/` + 单字/两字词元 + BM25，零依赖、结果可解释），不是向量检索；`knowledge/songs/`、`strategies/` 尚未建。
- **弱网离线模式**：内置 Service Worker 离线外壳——外壳（HTML/CSS/JS/课程数据，约 250KB）装时缓存，参考音频等大件用到才缓存，并后台补一个最小离线包；断网时已打开过的页面与已缓存的参考音频照常可用，而录音测量、登录这些要真数据的功能会如实提示「需要连接本机服务」，不拿旧数据冒充新结果。
- **儿童大字模式**：教师端账号菜单、学生端菜单、学生大屏三处可切换（`html.big-text`），只放大字号与按钮，不动任何测量与判定；选择会被记住。
- 录音按保留期**课后自动删除**（默认 30 天，`AUDIO_RETENTION_DAYS` 可配，`0` 关闭）：到期只删音频本体，测量与诊断记录保留并如实标注「音频已删除」。
- 仍未做：端侧离线分析（测量仍在服务端）、儿童端独立交互形态、监护授权／伦理流程。

详细缺口见 `docs/功能缺口清单.md`。

## 开发约定

- 服务端与前端逻辑分离：`public/` 只放浏览器代码，`server/` 只放 Node 代码，`lesson-core.js` 为两端共用的纯算法。
- 先本地实现与验收，不擅自部署或推送线上版本。
- 测试一律使用临时目录，不读写 `.local-data/`。
